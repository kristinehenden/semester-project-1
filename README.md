# Community Science Museum

Semester Project 1 for the Front-end Development program at Noroff.

## About the project

The project is a responsive website for the Community Science Museum. The website is designed for children aged 7–15 and families, with a focus on making science engaging, accessible and easy to explore.

The website includes five pages:
- Home
- Explore
- Exhibitions
- Visit
- Get Involved

## Built with

- HTML
- CSS

## Design

The website is based on a responsive design created in Figma, with a focus on accessibility, clear navigation and a playful visual identity.

## Development and progress

The five main pages have been built with HTML and CSS: Home, Explore, Exhibitions, Visit and Get Involved.
A Coming Soon page has also been added for content and features that are not yet available.

The development work includes:
- Shared navigation, footer, buttons and reusable styles.
- Page sections based on the Figma designs and museum content.
- Font Awesome icons. and decorative elements.
- Image compression, conversion to WebP and descritive alt text.
- Page titles, meta descriptions and internal navigation links.
- Responsive adjustments for mobile, tablet and desktop. 

The pages have been visually compared with the Figma designs. Browser chacks have led to improvements in spacing, image scaling, card layouts, badge placement and the tablet footer.

Internal links have been manually tested, including adjustments to the scroll position for Opening hours and Accessibility.
