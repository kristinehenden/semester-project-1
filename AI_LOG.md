# AI Usage Log

AI has been used as a support tool throughout the project. Two tools were used: ChatGPT, mainly for image generation and support during planning, design, development, testing and documentation, and Claude, mainly for reviewing my work and helping with design and development throughout the project, including checking the finished site against the assignment brief.

## Planning and design

I used ChatGPT and Claude to help me understand the project brief, organize the project tasks and discuss ideas for the website structure and design.

During the design process, I used AI to explore different visual directions, layouts and design ideas. I used the suggestions as inspiration and made my own decisions and adjustments while creating the final designs in Figma.

AI was also used to review parts of the design, including layout, readability, responsive design and accessibility.

## Images

The images used in my final design were generated with ChatGPT. I generated and tested several different images before choosing the ones that suited the content and visual direction of the website.

## Development

I used ChatGPT and Claude to help me understand the project structure, Git and GitHub, and to work through the development tasks on my project board.

During development, I received explanations, HTML and CSS suggestions, and code examples for sections of the website. I entered and adapted these in VS Code, compared the results with my Figma designs and made further adjustments.

The assistance covered shared components, page layouts, responsive styling, icons, image sizing, navigation links and decorative elements. I also asked for explanations and simpler alternatives when suggested CSS techniques were unfamiliar to me.

Because parts of my design included more complex visual elements (such as decorative shapes and layout effects), some sections required AI assistance to implement correctly. I reviewed the code suggestions after implementation to ensure I understood how they worked and how they were integrated into the project.  

## Testing and troubleshooting

I shared screenshots of the website and Figma designs to discuss differences in spacing, typography, colours, images and alignment.

I tested changes in the browser at mobile, tablet and desktop sizes. Adjustments included the tablet footer, card widths, badge positions and decorative elements that caused horizontal scrolling.

ChatGPT and Claude also helped identify HTML and CSS mistakes, including incorrect class names, misplaced closing tags and rules placed in the wrong media query.

Some suggestions required several revisions. I tested the results and provided feedback when changes did not work or match the intended design. 

## Documentation

ChatGPT and Claude helped me keep track of the work completed throughout the project. This made it easier for me to update the README and AI usage log as the project developed.

I reviewed and updated the documentation myself to ensure it accurately described my process and the assistance I received.
