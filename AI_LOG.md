# AI Usage Log

AI has been used as a support tool throughout the project.

## Planning and design

I used ChatGPT to help me understand the project brief, organize the project tasks and discuss ideas for the website structure and design.

During the design process, I used AI to explore different visual directions, layouts and design ideas. I used the suggestions as inspiration and made my own decisions and adjustments while creating the final designs in Figma.

AI was also used to review parts of the design, including layout, readability, responsive design and accessibility.

## Images

The images used in my final design were generated with AI. I generated and tested several different images before choosing the ones that suited the content and visual direction of the website.

## Development

I used ChatGPT to help me understand the project structure, Git and GitHub, and to work through the development tasks on my project board.

During development, I received explanations, HTML and CSS suggestions, and code examples for sections of the website. I entered and adapted these in VS Code, compared the results with my Figma designs and made further adjustments.

The assistance covered shared components, page layouts, responsive styling, icons, image sizing, navigation links and decorative elements. I also asked for explanations and simpler alternatives when suggested CSS techniques were unfamiliar to me.

## Images and icons

ChatGPT provided guidance on image compression and file formats. I converted content images to WebP, reduced their file sizes and updated the image paths.

I also received assistance with descriptive alt text and with adding Font Awesome icons and arrows.

## Testing and troubleshooting

I shared screenshots of the website and Figma designs to discuss differences in spacing, typography, colours, images and alignment.

I tested changes in the browser at mobile, tablet and desktop sizes. Adjustments included the tablet footer, admission card widths, badge positions and decorations that caused horizontal scrolling.

ChatGPT also helped identify HTML and CSS mistakes, including incorrect class names, misplaced closing tags and rules placed in the wrong media query.

After testing internal links, I adjusted the scroll spacing for Opening hours and Accessibility. Some suggestions required several revisions, and I provided feedback when the results did not work or match the intended design.

## Coming Soon page

ChatGPT suggested the initial text, HTML and CSS for the Coming Soon page, which did not have a separate Figma design.

I implemented and revised the suggestions to fit the rest of the website, including changes to the layout and decorative circles.

## Documentation

ChatGPT helped summarise the work for the README and this AI usage log. I review the documentation to ensure it reflects the work carried out.

The AI usage log will also be included in the final reflection report.
